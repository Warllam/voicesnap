1. Launch VoiceSnap Apple Edition:
   ```bash
   python3 voicesnap_apple.py
   ```

2. Add some sample transcriptions (use dummy text if needed)

3. Take screenshots with:
   - **macOS**: Cmd+Shift+4, then spacebar (window capture)
   - **Windows**: Win+Shift+S

4. Save as PNG in `/assets/` directory

5. Update README_APPLE.md image links
